# 興櫃 15% 起漲・主力續航雷達

本專案掃描全部興櫃股票。最新成交價相對前一交易日加權均價嚴格大於 15% 時建立事件，保存首次觸發，並用事件前已公布的分點資料追蹤核心資金是否續抱。

入口採「第一根」：前 10 日振幅不超過 20%、突破區間高點、成交量至少為前 20 日中位量 2 倍，且前 5 日沒有 10% 以上先行漲幅。每檔每日最多一次，首次突破後 20 個交易日內不重複開新事件，只更新同一事件。

盤中只能取得即時價格與成交量；當日分點承接必須等盤後完整 `EMdss004` 才確認。網站會分開顯示行情時間與分點資料日。

## 本機執行

- `run_intraday.bat`：盤前建立核心快取，09:00–15:05 每 60 秒掃描，每 10 分鐘嘗試發布。
- `run_eod.bat`：盤後更新歷史研究、核心分點與網站資料。
- `run_backtest.bat`：單獨重跑時間點凍結的主力條件研究。
- `setup_schedule.ps1`：註冊週一至週五 08:50 與 18:15 的 Windows 工作排程。

第一次執行研究：

```powershell
python radar.py research
```

GitHub Pages 請設定為 `main` 分支的 `/docs`。尚未設定 Git remote 時，BAT 仍會正常保存本地資料，只略過發布。
